# Dugu Dugu Battle - Railway Online Multiplayer

1. Put all game images inside the `public` folder, next to `index.html`.
2. Run locally:

```bash
npm install
npm start
```

Open http://localhost:3000

3. Push this entire folder to GitHub.
4. In Railway: New Project -> Deploy from GitHub repo -> select repo -> Deploy Now.
5. After deployment: Settings -> Networking -> Generate Domain.
6. Both players open the Railway URL. One creates a lobby; the other joins with the code.

Guest controls: WASD or arrow keys.
